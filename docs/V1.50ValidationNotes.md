# GAC EA v1.50 validation notes

The current source adds explicit controls requested by the readiness review: maximum equity drawdown entry lock, consecutive-loss lockout, notional exposure cap, margin pre-check, broker-derived volume precision, structured signal/entry logs, and break-even/ATR trailing management.

These controls are protective gates; they cannot make a strategy guaranteed to win. The equity drawdown guard compares current equity with current balance and is an entry guard, not an emergency liquidation mechanism. The daily-loss calculation remains scoped to the current symbol and MagicNumber, so portfolio-wide risk must be managed separately when multiple charts or systems run on one account.

Before demo:

1. Compile `Experts/GAC_EA/GAC_EA.mq5` in MetaEditor with zero errors and no unexplained warnings.
2. Verify `MaxSpreadPrice`, contract size, volume step, stop level, and session hours for the broker/server.
3. Test failed orders, invalid stops, margin rejection, loss lockouts, and trailing modifications in a demo environment.
4. Run the documented real-tick, out-of-sample, stress, and walk-forward tests.
5. Freeze the source commit and input set for the demo period.
